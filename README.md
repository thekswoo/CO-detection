# 불침번 (CO-detection)

차박·캠핑카 환경의 **일산화탄소(CO) 중독 방지 경보 시스템**입니다.
STM32L476(NUCLEO-L476RG)에서 **HAL 없이 레지스터 레벨**로 펌웨어를 작성하고, **FreeRTOS** 멀티태스킹으로 측정 → 판정 → 경보 파이프라인을 구성했습니다.

> 제24회 임베디드SW경진대회 자유공모 부문 참가를 준비하며 개발한 프로젝트입니다.

---

## 주요 기능

- **CO 측정**: MQ-7 센서를 ADC로 주기 측정 (하드웨어 64배 오버샘플링 + EMA 필터)
- **적응형 기준선 판정**: 절대값이 아니라 "기준선 대비 상승량(delta)"으로 위험도 3단계 판정
- **경보 출력**: 3색 LED(안전/경고/위험) + PWM 부저
- **취침 모드**: 감지 주기 단축(1000ms → 300ms), 임계값 약 70%로 하향, 부저를 공진주파수로 구동해 최대 음압
- **음소거**: 부저만 정지하고 측정·판정·LED 표시는 계속 유지
- **자가진단**: 부팅 시와 버튼 입력 시 LED·부저를 순차 구동해 하드웨어 정상 여부 확인
- **UART 로그**: 측정값, 기준선, delta, 위험도, 모드를 실시간 출력

## 하드웨어

| 구성 | 부품 | 연결 |
|---|---|---|
| MCU | NUCLEO-L476RG (Cortex-M4F) | — |
| CO 센서 | MQ-7 | PA0 (ADC1_IN5), 10kΩ/10kΩ 전압분배 (5V → 2.5V) |
| 부저 | GEC09D + KSP2222A NPN 트랜지스터 | PA1 (TIM2_CH2 PWM) |
| 위험도 LED | 초록 / 노랑 / 빨강 | PB0 / PB1 / PB2 |
| 모드 RGB LED | 공통음극 | PC0 / PC1 / PC2 |
| 버튼 1 (모드 토글) | 택트 스위치 | PB5 (EXTI5, 내부 풀업) |
| 버튼 2 (음소거) | 택트 스위치 | PC7 (EXTI7, 내부 풀업) |
| 자가진단 | 보드 내장 B1 | PC13 (EXTI13) |
| 로그 | USART2 115200bps | PA2 (TX) |

## 소프트웨어 구조

```
[EXTI ISR] --xQueueButton--> Task_Mode (모드 전환 / 음소거 / 자가진단)

Task_Sensor --xQueueSensorToJudge--> Task_Judge --xQueueJudgeToOutput--> Task_Output
 (ADC, 필터,                          (임계값 판정)                        (LED, 부저, UART 로그)
  기준선 학습)
```

| 태스크 | 역할 | 우선순위 |
|---|---|---|
| Task_Sensor | ADC 측정, EMA 평활화, 적응형 기준선 학습, delta 계산 | 높음 |
| Task_Judge | delta 기반 위험도 판정 (모드별 임계값) | 높음 |
| Task_Output | LED / 부저 / UART 로그 출력 | 중간 |
| Task_Mode | 버튼 이벤트 처리 | 중간 |
| Task_Heartbeat | 스케줄러 생존 신호 (LD2 점멸 + UART 카운터) | 낮음 |

- FreeRTOS는 CMSIS-RTOS 래퍼 없이 **네이티브 API로 수동 통합** (`ARM_CM4F` 포트, heap_4)
- 모든 페리페럴(GPIO, ADC, USART, TIM, EXTI)은 **CMSIS 레지스터 직접 접근**으로 설정

## 검증 기록

### ADC 기본 동작

| 입력 | ADC 출력 | 판정 |
|---|---|---|
| GND 직결 | 0 | PASS |
| 3.3V 직결 | 4091 ~ 4093 | PASS |
| 대기 중 MQ-7 (예열 후) | 61 ~ 73 | 정상 범위 |
| 알코올 솜 노출 | 상승 후 피크 기록 | 반응 확인 |

### 발견한 문제와 해결

| 문제 | 원인 | 해결 |
|---|---|---|
| ADC 변환은 정상인데 값이 약 70에 고정 | STM32L47x 전용 `GPIOx_ASCR` 아날로그 스위치가 열려 있음 | `GPIOA->ASCR`의 ASC0 비트 설정 |
| 센서 절대값이 부팅마다 달라지고 드리프트 (40 → 366 → 184) | MQ-7 히터 사이클링 없이 상시 구동, 예열 부족 | 고정 임계값 대신 **적응형 기준선 대비 상승량(delta)** 으로 판정 |
| 자극 후 기준선이 높게 남아 경보 감도 저하 | 기준선 상승·하강 추종 속도가 대칭 | 하강 추종을 5배 빠르게 (비대칭 시정수 300s / 60s) |
| 모드 전환 시 필터 특성 변화 | 이동평균 창이 샘플 개수 기준 | 시간 상수 기준 EMA로 교체 |
| 버튼을 연달아 누르면 입력 유실 | 세마포어 + 전역변수 구조에서 덮어쓰기 | ISR → 큐(`xQueueButton`) 구조로 변경 |

### 임계값 근거

- 필터 적용 후 평상시 delta 변동 폭: 1~2 counts 미만
- 알코올 솜 반응 피크: delta 408 counts
- **위험(DANGER) = 150**: 피크의 약 37%, 노이즈 대비 약 100배 여유
- **경고(WARN) = 40**: 변환 노이즈가 아니라 기준선 드리프트(수십 counts)를 기준으로 설정
- 취침 모드는 일반 모드의 약 70% (경고 28 / 위험 105)
